# 📊 Excel Data Analysis – Superstore Dataset

## 📌 Project Overview

This project focuses on analyzing the Sample Superstore dataset using Microsoft Excel. The analysis was performed to understand sales, profit, customer segments, product categories, regional performance, and monthly sales trends.

The project demonstrates basic data analysis techniques such as sorting, filtering, Excel formulas, PivotTables, KPIs, and charts.

---

## 🎯 Objectives

- Analyze overall sales and profit performance.
- Identify sales performance across different product categories.
- Compare sales across different regions.
- Analyze monthly sales trends.
- Understand profit contribution by category.
- Analyze sales generated by different customer segments.
- Create meaningful KPIs and visualizations.

## 📑 Workbook Structure

The Excel workbook contains the following sheets:

### 1. Raw Data
Contains the original Superstore dataset. The raw data is maintained separately for reference and analysis.

### 2. Working
Contains calculations and formulas used for analysis, including:

- `SUM`
- `SUMIFS`
- `COUNTIFS`
- `AVERAGE`
- `AVERAGEIFS`

It also contains basic KPIs such as:

- Total Sales
- Total Profit
- Total Quantity
- Average Sales
- Average Profit
- Number of Orders
- Average Discount

### 3. Pivot Tables

Five PivotTables were created to answer important business questions:

1. **Sales by Category**
2. **Sales by Region**
3. **Monthly Sales Trend**
4. **Profit by Category**
5. **Sales by Segment**

### 4. Summary

The Summary sheet presents the main KPIs, charts, and key findings from the analysis.

## 💡 SUMIFS vs PivotTable

**SUMIFS** is useful when a specific value needs to be calculated based on one or more conditions.

**PivotTables** are useful for quickly summarizing, comparing, and exploring large datasets across categories, regions, months, or other dimensions.
