📊 Task

First Chart Story: Turning Numbers into a Narrative

🎯 Objective

The objective of this task is to learn how to choose the right basic
chart type for a specific question and present data insights clearly.

The task focuses on creating 3--4 simple and clearly labeled charts
that each answer a specific question and combining the findings into one
short data narrative.

🛠️ Tools Used

Microsoft Excel

Google Sheets

Python (Matplotlib) -- Optional

📂 Dataset

The analysis is performed using a small dataset suitable for basic data
visualization.

Suggested Datasets

Iris Dataset

World Happiness Report

📈 Visualizations Created

1. Bar Chart

A bar chart is used to compare values across different categories.

Question Answered:
Which categories have higher or lower values?

Key Takeaway:
The bar chart makes it easy to compare values across different
categories and identify the highest and lowest values.

2. Line Chart

A line chart is used to show trends or changes over time.

Question Answered:
How does the selected value change over time?

Key Takeaway:
The line chart helps identify trends, increases, decreases, and changes
across the selected time period.

3. Pie Chart

A pie chart is used to show the proportion or percentage contribution of
different categories.

Question Answered:
What proportion does each category contribute to the overall total?

Key Takeaway:
The pie chart provides a simple view of how the total is distributed
among different categories.

Note: Pie charts are kept to a small number of categories for better
readability.

4. Additional Chart

An additional suitable chart can be used to provide another perspective
of the dataset.

Question Answered:
What additional pattern or comparison can be identified from the data?

Key Takeaway:
The additional visualization provides another perspective and supports
the overall data story.

📝 Chart Design Principles Followed

Selected chart types based on the question being answered.

Added clear and descriptive chart titles.

Added appropriate axis labels.

Used simple and easy-to-understand visualizations.

Avoided unnecessary complexity.

Kept pie charts to a maximum of five slices where applicable.

🔎 Key Analysis

The charts were created to transform raw data into simple visual
insights. Each visualization focuses on a specific question rather than
simply displaying data.

The bar chart helps compare categories, while the line chart
highlights trends and changes. The pie chart shows how values are
distributed across categories. Together, these charts provide different
perspectives of the dataset and make the information easier to
understand.

📖 Data Story

The visualizations demonstrate how different chart types can communicate
different aspects of the same dataset. Comparisons can be understood
through bar charts, trends can be identified using line charts, and
proportions can be communicated through pie charts. By selecting the
appropriate chart for each question and adding clear takeaways, the
analysis turns numbers into a simple and meaningful narrative.
