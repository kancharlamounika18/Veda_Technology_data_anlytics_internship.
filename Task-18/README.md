Dataset Information

The screenshot suggested the Superstore dataset but did not include an official source file. Therefore, this project uses a clearly labeled compact Superstore-style practice dataset created for this assignment.

The dataset contains 32 records covering four regions:

•
East

•
West

•
Central

•
South

It includes sales and profit values suitable for regional comparison and dashboard practice.


This is practice data, not the official Tableau Superstore dataset. If an official dataset is provided by the instructor, replace the records in the Excel workbook's Data sheet while keeping the same column names.




Excel Formulas Used

•
Total Sales: SUMIF

•
Total Profit: SUMIF

•
Profit Margin: IFERROR(Total Profit / Total Sales, 0)

•
Sales Rank: RANK

•
Profit Rank: RANK

•
Order Count: COUNTIF

The formulas are linked to the Data sheet so that the summary updates when the source records are changed.




Main Finding from the Practice Dataset

Based on the included practice data:

•
West is the top region for total sales.

•
West is also the top region for total profit.

•
Central has the highest profit margin among the four regions.
