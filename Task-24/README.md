# Task-24-Excel-PivotTable-Basics

Sample Superstore Sales Analysis
GitHub Repository Name: Excel-PivotTable-Basics

Tool: Microsoft Excel

Dataset: Sample Superstore
##Objective
Create PivotTables for sales analysis by category, region, and month using the Sample Superstore dataset.

## Workbook
The complete project is available in:
Excel-PivotTable-Basics.xlsx

##Workbook Sheets
Read Me — Project details, dataset information, and instructions
Superstore_Data — Raw Sample Superstore sales data with 10,800 records
Pivot_Category — Sales, profit, quantity, orders, and discount summary by category
Pivot_Region — Sales, profit, quantity, orders, and discount summary by region
Pivot_Month — Monthly sales, profit, quantity, and order summary
Insights — Short business insights based on the summaries

##Deliverables
Three PivotTable-style summaries
Sales analysis by category
Sales analysis by region
Sales analysis by month
Charts for the summary tables
Short business insights

##Key Metrics
The workbook summarizes the following metrics:
Sales
Profit
Quantity
Number of orders
Average discount
Monthly performance
Inventory and category-level performance observations

##Dataset Source
The workbook uses the public Sample Superstore dataset from:
https://github.com/leonism/sample-superstore

##How to Use
Download and open Excel-PivotTable-Basics.xlsx in Microsoft Excel.
Review the Superstore_Data sheet for the source records.
Open each Pivot_ sheet to review the grouped summaries.
Use the charts to compare performance visually.
Read the Insights sheet for the main business findings.
