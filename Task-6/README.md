# Task-6-Excel-Formulas-Functions-Fundamentals.
📌 Internship

Veda Technology – Data Analytics Internship

📋 Task

Excel Formulas & Functions Fundamentals

🎯 Objective

To practice commonly used Excel formulas and functions on the Superstore dataset and build fluency with everyday Excel functions used in data analysis.

🛠️ Tools Used
Microsoft Excel
Superstore Dataset
📊 Functions Covered
VLOOKUP – Retrieve related information from a table
XLOOKUP – Perform flexible lookup operations
IF – Apply conditional logic
SUMIFS – Calculate totals based on multiple conditions
COUNTIFS – Count records based on multiple conditions
LEFT – Extract characters from the beginning of text
RIGHT – Extract characters from the end of text
LEN – Count the number of characters
UPPER – Convert text to uppercase
LOWER – Convert text to lowercase
PROPER – Format text with proper capitalization
TRIM – Remove unnecessary spaces
📁 Workbook Sheets
Raw Data – Original Superstore dataset
Lookup – VLOOKUP examples for Customer Name, Region, and Sales
XLOOKUP – Lookup and error-handling practice
IF – Sales classification using conditions
SUMIFS – Total Sales by Region and Category
COUNTIFS – Number of records by Region and Category
Text Functions – Text extraction and formatting functions
Notes – Purpose and usage of each function
🔍 Key Work Performed
Practiced lookup operations using customer and order information.
Classified sales values using conditional statements.
Calculated total sales using multiple criteria.
Counted records based on multiple conditions.
Applied text functions for data cleaning and manipulation.
Tested formulas with blank cells and invalid Order IDs.
Added notes explaining when each function can be used.
📌 Edge Case Testing

The workbook includes tests for:

Valid Order IDs
Invalid Order IDs
Blank input cells
Missing lookup values
Text manipulation
