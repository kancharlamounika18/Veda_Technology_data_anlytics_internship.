# 📊 Basic Sales Summary

## Project Overview

This project is part of my **Data Analytics Internship at Veda Technology**. The objective is to analyze retail sales data using **Microsoft Excel** and create a basic sales summary with three key KPIs: **Total Sales, Average Sales, and Transaction Count**.

## Objective

* Calculate total sales.
* Calculate average sales per transaction.
* Calculate total number of transactions.
* Create a summary sheet with 3 KPIs.
* Verify the calculated results manually.

## Tools Used

* Microsoft Excel
* Retail Sales Dataset

## KPIs

* **Total Sales:** Overall revenue generated from all transactions.
* **Average Sales:** Average sales value per transaction.
* **Transaction Count:** Total number of recorded transactions.

## Excel Formulas

```excel
=SUM(Sales_Range)
```

```excel
=AVERAGE(Sales_Range)
```

```excel
=COUNTA(Transaction_ID_Range)
```

## Process

1. Imported the retail sales dataset into Excel.
2. Organized the data in the **Raw Data** sheet.
3. Created a **Summary** sheet.
4. Calculated the three KPIs using Excel formulas.
5. Formatted sales values using ₹ currency format.
6. Verified the calculated totals manually.
7. Presented the results in a clear and professional summary.
