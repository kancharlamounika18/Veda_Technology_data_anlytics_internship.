# Task-3-Sales-Performance-Dashboard

## Project Overview

This project is a **Simple Sales Performance Dashboard** created using
**Microsoft Power BI**.

The objective is to turn sales data and key performance indicators
(KPIs) into an interactive, easy-to-understand dashboard that can be
used to analyze sales performance by **product, region, and month**.

## Tool Used

-   Microsoft Power BI

## Dashboard KPIs

The dashboard contains the following key performance indicators:

-   **Total Sales:** 474.24K
-   **Total Profit:** 64.35K
-   **Units Sold:** 8K
-   **Profit Margin:** 13.57%

> KPI values may change if the underlying dataset or filters are
> changed.

## Dashboard Visualizations

The dashboard includes:

1.  **Sales by Region** -- shows sales performance by region.
2.  **Sales by Month** -- shows the monthly sales trend.
3.  **Sales by Category** -- compares sales across product categories.
4.  **Top Products by Sales** -- highlights products with higher sales.
5.  **Order Date Slicer** -- allows users to filter the dashboard by
    date.
6.  **Region Filter** -- allows users to view results for a selected
    region.

## How to Read the Dashboard

Start with the four KPI cards at the top to get a quick overview of
sales performance.

Then use the charts to understand:

-   Which regions generate sales
-   How sales change over time
-   Which categories contribute to sales
-   Which products have higher sales

Use the **Order Date** and **Region** filters to interact with the
dashboard and analyze a specific time period or region.

## Dataset

The dashboard is based on sales/order data containing fields such as:

-   Order Date
-   Region
-   Product Name
-   Product ID
-   Category
-   Sales
-   Profit
-   Quantity
-   Discount
-   Customer information
-   Ship Date
-   Ship Mode

## Project Objective

The main objective of this project is to create a basic interactive
dashboard that presents sales performance clearly and allows
stakeholders to explore the data using KPIs, charts, and filters.
